# BB Attack - Edge-based Image Clustering for Memorization Detection

## Overview
BB Attack is a tool to detect memorized or nearly identical images generated by unconditional diffusion models by clustering images based on their edge similarity. It uses edge detection to extract the structural features of each image, compares them efficiently with FAISS, constructs a similarity graph, and identifies clusters of virtually identical images. This helps uncover memorization artifacts in generative models.

## Features
- Extracts edge maps from images using Sobel filters
- Efficient nearest neighbor search of edge features via FAISS
- Graph-based clustering of images using connected components
- Outputs clustering results with edge scores, MSE to cluster reference, and similarity scores
- Adjustable hyperparameters like similarity threshold, minimum cluster size, and neighborhood size

### Important parameters:
- `--samples_folder`: Folder containing input images (PNG)
- `--out_parquet_file`: Output parquet file with cluster results
- `--similarity_threshold`: Minimum edge similarity to consider images connected (default 0.99)
- `--min_cluster_size`: Minimum number of images in cluster to report (default 2)
- `--k`: Number of neighbors to search per image in FAISS (default 10)
- `--verb`: Verbose output

### Explanation of `k` and `min_cluster_size`:

- **`k` controls how thoroughly neighbor search is done for each image.** It defines how many nearest neighbors FAISS considers for each image vector. A larger `k` means more neighbors are examined, potentially resulting in larger clusters because more connections between similar images can be found.

- **`min_cluster_size` defines the minimum size for a cluster to be reported.** Only clusters with at least this many images appear in the output. Smaller clusters are ignored.

- To find clusters with at least `min_cluster_size` images, set `k` to at least `min_cluster_size - 1`. This ensures that enough neighbors are checked to form such clusters (better a bit higher for reliability).

## Output
The parquet file contains:
- `filename`: Image filename
- `cluster`: Cluster ID assigned
- `edge_score`: Mean edge pixel intensity per image
- `mse_to_ref`: Mean squared error to cluster reference image’s edge vector
- `faiss_similarity_to_ref`: FAISS similarity score to cluster reference 

Clusters of similar images help identify memorized or duplicated generations.

## Example Workflow
1. Collect generated images in `samples/`.
2. Run the BB Attack script with desired parameters.
    -> e.g.: python run_bb_attack.py --samples_folder samples --out_parquet_file clusters.parquet --similarity_threshold 0.95 --k 20 --min_cluster_size 2
3. Inspect the resulting parquet for clusters and similarity details.
4. Use clusters to analyze memorized training data images.
